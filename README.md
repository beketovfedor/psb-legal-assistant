# Юридический ассистент ПСБ

Проект для кейса ПСБ на Hack&Change 2026. Ассистент будет искать положения в выданной базе знаний, показывать документы и пункты, на которых основан ответ, и объяснять, каких сведений не хватает для вывода.

## Материалы кейса

- [База знаний, демо-вопросы и пример сабмита](https://drive.google.com/drive/folders/1lendasLVlcKUcuM8mOrWKHD-C2dWtm9F)
- [Технический регламент секции ПСБ](https://docs.google.com/document/d/1GjOSBr6xtiweDrMI5Kvcnug4wcbHCzg7n5TJ4UBnuxg)

## Разработка

1. Скачайте `knowledge-base.zip` и `demo_questions.csv` из папки организаторов. Положите архив в локальный каталог `data/`, а демо-вопросы сохраните там же под именем `questions.csv`.
2. Для локальных вызовов модели используйте `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL`. Имена настроек собраны в `.env.example`. Платформа подставляет значения автоматически. Ключи и локальные данные исключены из Git.
3. Первый сценарий для проверки поиска — вопрос об аренде у ООО «Северный Склад». Поиск должен вернуть точный текст пунктов 3.1 и 3.2 договора № А-08/2024.

## Сдача

- Лидерборд запускает `solution.py` и ожидает `submission.csv` с колонками `id,answer`.
- Для финальной сдачи потребуется веб-чат с просмотром источников и запуск через Docker Compose. Поиск и формирование ответа будут общими для скрипта и чата.

Репозиторий пока содержит стартовые настройки проекта.
